An entry for the make.fun contest "One Emoji, One Dream Vacation" — exactly one emoji for a dream vacation, judged on how much it makes a stranger want to book the flight. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes a single emoji to `/output/entry.txt`: 🌅, the sun rising over the sea — dawn on the water, the first morning of the trip you have been dreaming about. A postcard moment rather than a generic beach icon: warm light, open water, somewhere far from home, specific and instantly readable at any size.
